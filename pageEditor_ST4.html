Profile Page

Technical Description

  • <div id="sample-data-container"> holds dynamic profile cards.
  • <div id="profileBuilder"> holds the interactive profile builder.
  • profile stores the current profile data.
  • sampleProfiles is an array of pre-filled profiles.
  • renderSampleData() displays sample profiles, clearing the container first, looping through sampleProfiles, and generating cards while skipping empty fields.
  • createCreateButton() adds a "Create New Profile" button that triggers createProfile() when clicked, and is prepended to the page.
  • saveProfile() saves a new profile with a random photo, replaces skipped fields with empty strings, prepends it to sampleProfiles, clears and hides the builder, and re-renders the profiles.
  • clearProfile() resets the builder after confirmation, sets fields to "Not Added Yet," and resets the progress bar.
  • createProfile() shows the builder with steps, progress bar, fields, and a Save button.
  • step1() collects basic info (name, age, country, role).
  • step2() collects interests (issue, animal, activity).
  • step3() collects goals and actions (goal, volunteer, awareness).
  • updateProgress() calculates filled fields and updates the progress bar.
  • renderProfile() updates displayed fields with current profile values, leaving blanks if empty.

Sample Profile Cards:

  • #sample-data-container is a responsive 3-column grid with gaps and width control.
  • .sample-data cards are flex columns with padding, dark background, rounded corners, and hover effects (transform, border, shadow).
  • .name is bolded.
  • .header contains .country and .role badges with distinct border colors (#ef4444 and #f59e0b) and background.
  • .profile-photo ensures images fit, maintain aspect ratio, and are rounded.
  • .details displays label-value pairs horizontally, with bold labels of fixed width.

Profile Builder (#profileBuilder):

  • Hidden by default (display: none) and styled as a flex column with padding, rounded corners, dark background, and opacity.
  • <h1> is larger and bold.

Progress Bar:

  • .progressContainer defines a bordered container for the progress bar with rounded corners.
  • .progressBar fills the container width based on completion and transitions smoothly.

Profile Sections:

  • .profile is a vertical flex container for sections.
  • .profile-section has borders, padding, rounded corners, hover effects, and is hidden initially.
  • .profile-row aligns labels and values horizontally with a bottom border; labels have fixed width and bold font.
  • .save button container is hidden initially.

Interactions:

  • Hovering over cards or profile sections triggers subtle transformations and shadows to indicate interactivity.
  • Progress bars animate width changes smoothly as the user fills profile fields.

Accessibility

  • Semantic HTML elements like h1, h3, p, and button are used for clear structure and screen reader support.
  • All buttons and interactive elements have visible labels, hover/focus states, and sufficient color contrast for readability.
  • Images include alt text to describe profile photos.
  • The progress bar provides both visual and text indicators to clearly show completion status.
